# Moghimi VPN برای ویندوز

نسخهٔ ویندوز مقیمی اکنون بر پایهٔ کلاینت رسمی **v2rayN (WPF)** ساخته می‌شود؛ موتور اتصال و مدیریت پروفایل‌ها از upstream می‌آید و امکانات مقیمی به‌صورت لایهٔ تکمیلی به آن متصل شده‌اند. این شاخه، شاخهٔ مهاجرت و آزمایش است و هنوز انتشار Stable محسوب نمی‌شود.

## مبنای فنی
- upstream: https://github.com/2dust/v2rayN
- commit ثابت‌شده: `2b5c7ca75b9163ec49cb4941b18388a061c3d96d`
- پروژه: `vendor/v2rayN/v2rayN/v2rayN/v2rayN.csproj`
- رابط: WPF، .NET 10، Windows x64
- هسته‌ها: Xray و sing-box؛ بسته‌بندی از اسکریپت رسمی upstream انجام می‌شود.
- مجوز v2rayN: GPL-3.0؛ الزامات ارائهٔ سورس متناظر و نگهداری اعلان‌های مجوز برای نسخهٔ مشتق‌شده باید رعایت شود.

## امکانات اختصاصی Moghimi
- ثبت دستگاه ویندوز مستقل از Android و iOS.
- شناسهٔ دستگاه از MachineGuid ویندوز به‌صورت پایدار ساخته می‌شود. فایل وضعیت/توکن با DPAPI رمز می‌شود و خارج از پوشهٔ نصب نگهداری می‌شود؛ بنابراین حذف و نصب دوبارهٔ خود برنامه روی همان نصب ویندوز، به‌طور معمول سهمیه را صفر نمی‌کند. نصب مجدد Windows یا تغییر MachineGuid می‌تواند دستگاه جدید محسوب شود.
- سهمیهٔ رایگان مستقل: **۸ GiB در هر ماه UTC**. پس از مصرف آن، حجم اشتراک خریداری‌شدهٔ ویندوز مصرف می‌شود.
- نمایش حجم رایگان و حجم اشتراک، همگام‌سازی دستی سرورها و فعال‌سازی کد خرید.
- فهرست سرورهای اختصاصی از جدول `windows_server_entries` در پروژهٔ Supabase ویندوز خوانده می‌شود.
- پروفایل‌های ابری Moghimi در گروه محافظت‌شده قرار می‌گیرند و عملیات کپی، اشتراک‌گذاری، Export، ویرایش و حذف برای آن‌ها محدود می‌شود؛ پروفایل‌های شخصی v2rayN مستقل و قابل مدیریت باقی می‌مانند.
- گزارش مصرف از آمار Proxy خود هستهٔ فعال Xray/sing-box خوانده می‌شود و به API ویندوز فرستاده می‌شود؛ ترافیک Direct به سهمیهٔ سرور نسبت داده نمی‌شود.
- رابط فارسی RTL، تم تیرهٔ شیشه‌ای با رنگ‌های بنفش/فیروزه‌ای، نورهای پس‌زمینهٔ متحرک، انیمیشن‌های ملایم و آیکن اختصاصی Moghimi.

## ساخت نصب‌کننده x64
روی Windows با Git، PowerShell و .NET 10:

```powershell
git clone --recurse-submodules https://github.com/MOGHIMI-IR/MOGHIMI_VPN_windows.git
cd MOGHIMI_VPN_windows
./integrations/patch-v2rayn.ps1
./vendor/v2rayN/package-windows.ps1 -Arch x64 -Flavor wpf -Version "2.0.0" -Output "dist-moghimi"
```

خروجی:
`vendor/v2rayN/dist-moghimi/MoghimiVPN-windows-64.exe`

اسکریپت رسمی upstream، باینری‌های x64 هسته‌ها و فایل‌های قواعد GeoIP/GeoSite را دریافت و در بسته قرار می‌دهد. Workflow شاخهٔ `v2rayn-foundation` نیز هش فایل‌های اجرایی، وجود فایل‌های اصلی، مجوز و اجرای اولیهٔ برنامه را بررسی و خروجی را به‌عنوان GitHub Actions Artifact نگه می‌دارد.

## زیرساخت مستقل ویندوز
- Supabase ویندوز: `hxfnoaeyjnkecegpppcy`
- GitHub: `MOGHIMI-IR/MOGHIMI_VPN_windows`
- API ویندوز، کدهای فعال‌سازی، اشتراک، مصرف، دستگاه‌ها و سرورهای ویندوز در پروژهٔ ویندوز نگهداری می‌شوند.
- هیچ Service Role Key یا Secret نباید در برنامهٔ دسکتاپ یا سورس قابل انتشار قرار بگیرد.
- جدول سرورهای ابری: `windows_server_entries`
- سهمیهٔ رایگان مستقل و پلن‌های خریداری‌شده در جداول ویندوز مدیریت می‌شوند.

## بات تلگرام
Router بات در `supabase/functions/moghimi-telegram-router` نگهداری می‌شود و API ویندوز در `supabase/functions/windows-api` است. Secretهای ربات و کلیدهای Supabase فقط باید در بخش Secrets/Environment پروژه ثبت شوند؛ آن‌ها را در GitHub، برنامه یا پیام عمومی قرار نده.

## امنیت و محدودیت تست
- کلید service-role در کلاینت وجود ندارد.
- فایل دستگاه با Windows DPAPI محافظت می‌شود.
- نصب‌کننده Defender را خاموش نمی‌کند و استثنای آنتی‌ویروس ایجاد نمی‌کند.
- Patchها و CI، کامپایل، بسته‌بندی و Smoke test اجرای اولیه را بررسی می‌کنند؛ این تست‌ها **جایگزین آزمایش واقعی VPN روی Windows 10/11 با سرور عملیاتی نیستند**. پیش از انتشار Stable باید اتصال Xray و sing-box، TUN/Wintun، DNS، IPv4/IPv6، قطع و وصل شبکه، Sleep/Resume، بازیابی Proxy و محاسبهٔ مصرف روی چند سیستم واقعی آزمایش شود.
