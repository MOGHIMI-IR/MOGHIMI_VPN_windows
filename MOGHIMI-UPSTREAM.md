# Moghimi Windows Client — upstream foundation

This repository is based on the official 2dust/v2rayN project, release tag 7.25.6.
The Windows WPF interface and existing Xray / sing-box connection stack are the upstream foundation.

Moghimi-specific UI, device identity, quota, activation and Supabase integration are maintained as modifications in this repository.
